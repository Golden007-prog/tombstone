# walkthrough-silent.mp4

A 46-second captioned walkthrough of the five beats, built from real screen captures of the
running app — no mockups, no reconstruction.

**It is not the submission video.** The submission needs a narrated screen recording per
`docs/DEMO-SCRIPT.md`, which is written and timed to 3:00. This exists so there is something
showing the product working even if the recording slips, and so the beats are already proven to
land visually.

Regenerate after a UI change: capture the five frames, then see the ffmpeg pipeline in the commit
that added this file.

| beat | what it shows |
|---|---|
| 1 | the corpus — 681 decisions, 958 rejected alternatives, 585 ownership files, all real |
| 2 | asking shallow: **nothing**, with a statement of what was searched |
| 3 | four hops: **0** of its named owners still approve, fallback to a parent with one approver |
| 4 | the path it actually walked |
| 5 | the refusal to overclaim — absence is not evidence of departure |
